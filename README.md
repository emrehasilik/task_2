# LocalCart

LocalCart, yerel üreticiler ile müşterileri buluşturan çok dilli ve SEO odaklı bir pazaryeri projesidir.

Repository şu anda tamamlanmakta olan backend uygulamasını içerir:

```text
task_2/
├── backend/    .NET 8 Auth ve Product servisleri
└── frontend/   Sonraki geliştirme aşamasında eklenecek
```

Backend mimarisi, kurulum adımları, Supabase ve Redis yapılandırması, API listesi ve test sonuçları için [backend dokümantasyonuna](backend/README.md) bakın.
